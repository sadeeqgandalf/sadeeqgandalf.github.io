% ------------------------------------------------------------------------------------- tracking
\project{Occlusion-Aware Multi-Object Tracking}{2026}
\begin{itemize}
  \item Built a tracker with EKF state estimation and Hungarian data association that models when each target is hidden from the sensor.
  \item Kept the correct identity through 1 to 5 second occlusions in \key{89\% of cases, up from 0\%}, across 20 Monte Carlo seeds in simulation.
  \item Cut identity switches per run from \key{75.6 to 6.6} by fusing camera, lidar and a second camera viewpoint.
  \item Validated against MathWorks GNN, JPDA and TOMHT trackers. Python, MATLAB and JavaScript implementations agree exactly.
  \item Runs in real time at \key{1.6 ms per frame}. Ported the companion navigation EKF to C++17 at 0.1 microseconds per step.
  \item Extended it with appearance re-identification, lidar instance segmentation at 0.94 mask IoU and an event camera model.
  \item Shipped a live 3D browser lab with 46 automated tests. Code at \href{https://github.com/sadeeqgandalf/lunar-occlusion-tracking}{github.com/sadeeqgandalf/lunar-occlusion-tracking}
\end{itemize}
