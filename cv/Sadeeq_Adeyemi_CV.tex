% ================= RESEARCH AND PROJECTS
\section{Research and Projects}
\entry{Occlusion-Aware Multi-Object Tracking}{\href{https://github.com/sadeeqgandalf/lunar-occlusion-tracking}{github.com/sadeeqgandalf/lunar-occlusion-tracking}}{2026}
\begin{itemize}
  \item Designed a tracker (EKF, Hungarian assignment, Bernoulli existence) that derives detection probability from 3-D line of sight and cast shadows, with a negative-information update for missed detections.
  \item Raised identities kept through 1--5 s occlusions from 0\% to 46\%, and to 89\% with appearance re-ID (20 seeds, 95\% intervals).
  \item Cut ID switches per run from 75.6 to 6.6 by fusing camera, lidar and a second viewpoint; showed that naive fusion raises them 3.4x.
  \item Cross-checked against MathWorks GNN, JIPDA and TOMHT; Python and MATLAB ports reproduce the JavaScript engine exactly.
  \item Rendered camera detections with PyTorch3D; appearance re-ID lifts identities kept after hides over 5 s from 8\% to 50\%.
  \item Shipped a live 3-D browser lab backed by 46 automated tests: \href{https://sadeeqgandalf.github.io/lunar-occlusion-tracking/track.html}{sadeeqgandalf.github.io/lunar-occlusion-tracking}
  \item Added lidar instance segmentation (0.94 mask IoU) and an event-camera sensor model fitted to real recordings (correlation 0.97).
\end{itemize}
