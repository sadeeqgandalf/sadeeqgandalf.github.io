Occlusion-Aware Multi-Object Tracking for Lunar Surface Operations2026 · independent

Python · PyTorch3D · MATLAB · JavaScript / Three.js — github.com/sadeeqgandalf/lunar-occlusion-tracking

  • Method. 3-D visibility model (line of sight against boulders, polar cast shadows) gives each track an expected detection probability, used in an EKF + Hungarian + Bernoulli-existence tracker with a negative-information update, p(x | miss) ∝ p(x)(1 − PD(x)).
  • Results (20 seeds × 300 s, 95% intervals). Identities kept through 1–5 s occlusions: 0% naive → 46% → 89% with appearance re-ID. ID switches per run: 75.6 → 6.6 fusing camera, lidar and a second camera.
  • Finding. Adding sensors to a tracker with no visibility model raises ID switches 3.4× (75.6 → 254); a second viewpoint helps more than a better sensor on the same mast.
  • PyTorch3D. Built from source on Apple Silicon; detections taken from rendered pixels (silhouette visibility, depth-map range, colour signature), with a windowed render ~20× faster and exact. Re-ID lifts same-ID after hides over 5 s from 8% to 50%; particle PHD filter maps where hidden people can be.
  • Verification. Python port matches the JavaScript engine exactly; checked against MathWorks GNN, JPDA and TOMHT trackers.
